Como funciona este acesso?

O FUTSTATS é um site estático, sem servidor. O painel edita os dados salvos neste navegador (localStorage), e nada que você mudar aqui afeta outras pessoas. Por isso a senha é pública: ela só evita edições por engano.

Mesmo assim, o código guarda só um hash SHA-256 da senha, pede alguns segundos de espera depois de 5 tentativas erradas e encerra a sessão após 12 horas. Para publicar os dados para todos, o painel gera o arquivo js/dados.js, que vai para o repositório.
